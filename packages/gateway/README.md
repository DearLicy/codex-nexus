# Codex Nexus Gateway

`server.mjs` is the local loopback aggregation gateway used by Codex Nexus.
It forwards Responses, Chat Completions and image requests to configured
provider routes, applies strict `namespace/model` routing, session affinity,
quota-aware account selection and cooldowns, and emits metadata-only logs.

Set `CODEX_NEXUS_CONFIG` to a generated JSON manifest before starting it. The
manifest is intentionally local and should be generated by the encrypted Rust
control plane rather than committed to the repository.

The image MCP server in `../image-mcp/server.mjs` exposes the same image pool
through `generate_image`, `edit_image`, `list_image_models` and `get_image_job`.
